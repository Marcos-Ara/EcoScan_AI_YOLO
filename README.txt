EcoScan AI — versão limpa para VS Code

Arquivos:
- index.html
- styles.css
- script.js

Como usar:
1. Abra a pasta no VS Code.
2. Instale a extensão Live Server.
3. Clique com botão direito em index.html > Open with Live Server.
4. Permita o acesso à câmera.

Importante:
- A câmera normalmente só funciona em localhost ou HTTPS.
- Se abrir o arquivo direto no navegador com file://, a câmera pode falhar.
- Esta versão usa o modelo COCO-SSD da TensorFlow para reconhecer objetos comuns e mapear para categorias de resíduos.
